## Prompt

/sp.constitution Project: Todo CLI Application – Intermediate Level (Phase I/II of Hackathon II)

Core principles:
- Simplicity: Commands must remain intuitive despite additional features
- Reliability: Tasks, priorities, tags, and statuses must update correctly
- Accuracy: Task status, priority, tags, and order always reflect user actions
- Modularity: Each feature (Add, Delete, Update, View, Mark Complete, Priorities, Tags, Search, Filter, Sort) should be implemented as independent, reusable functions
- Spec-driven: All implementation follows specifications generated by Claude Code

Key standards:
- Feature completeness: 
    - Basic features (Add, Delete, Update, View, Mark Complete)
    - Intermediate features:
        - Priorities: High / Medium / Low
        - Tags / Categories: Customizable labels (Work, Home, Personal, etc.)
        - Search: Find tasks by keyword
        - Filter: Filter tasks by status, priority, tag, or date
        - Sort: Order tasks by due date, priority, or alphabetically
- User prompts: Clear and informative messages for all commands, errors, and confirmations
- Data handling: Tasks stored in-memory as structured objects/dictionaries, with all attributes (title, description, status, priority, tags, due date)
- Code quality: Follow Python best practices (PEP8), clean function names, comments where necessary
- Testing: All commands should be testable via console input

Constraints:
- Command-line interface only
- No persistent storage (in-memory only for Phase I)
- Use Python 3.13+ with Claude Code & Spec-Kit Plus
- All code generated via Claude Code; manual coding prohibited
- Single-user application

Success criteria:
- Users can:
    - Add, update, delete, and mark tasks complete
    - Assign and update priorities
    - Assign and update tags/categories
    - Search, filter, and sort tasks efficiently
- Task data structure accurately reflects all attributes
- Console prompts are user-friendly and informative
- Code is modular, clean, and maintainable
- Project structure matches Hackathon requirements (README, /src folder, specs history, CLAUDE.md)
